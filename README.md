# App dos Sócios — Azevedo dos Reis

App interno, somente leitura, para os sócios acompanharem processos, bloqueios judiciais (SISBAJUD)
e reclamações constitucionais pelo celular. Next.js 16 + React 19, instalável como app (PWA).

```
npm install
npm run dev        # http://localhost:3000
npm run artifact   # versão de arquivo único para o claude.ai (dist/app-socios.html)
```

Contexto, decisões de design e estrutura do código: [CLAUDE.md](CLAUDE.md).
